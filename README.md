# RV32I RISC-V SoC: RTL to GDSII

A learning-oriented RISC-V processor and SoC project focused on digital design, RTL development, computer architecture, verification, FPGA prototyping, and ASIC physical design.

The goal is to develop a pipelined RISC-V processor in SystemVerilog, validate its behavior through simulation, deploy it on an FPGA, and eventually take the design through an ASIC implementation flow to GDSII.

> **Project status:** Core RTL development and initial simulation-based verification are in progress. FPGA integration and ASIC physical design are planned future milestones.
